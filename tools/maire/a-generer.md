# À générer : 4 planches du quartier

Ouvre une nouvelle conversation ChatGPT, colle le bloc STYLE, puis les 4 demandes une par une. Télécharge chaque image en PNG (fond blanc uni, ordre des cases respecté) et envoie-les à Claude.

## Bloc STYLE (à coller en premier)

```
Tu vas créer une série d'illustrations pour un jeu mobile de gestion de ville, « Maire de Paris ».
Style à respecter pour TOUTES les images de cette conversation :
- pixel art détaillé et chaleureux, vue isométrique de 3/4 (comme une carte illustrée de Paris vue d'en haut) ;
- toits en zinc gris-bleu, façades haussmanniennes crème, beaucoup de verdure vert vif, touches d'or ;
- contours nets, lumière douce venant d'en haut à gauche, petite ombre portée sous chaque objet ;
- couleurs : bleu marine #1b2550, crème #f7f2e7, or #f5b21a, vert #3fae68, bleu Seine #2b6fb3 ;
- jamais de texte, de lettres, de logos ou de chiffres dans les images ;
- aucune personne réelle ni marque réelle.
Réponds « Style compris » et attends mes demandes.
```

**Planche Q1 · Mairie**
```
Crée une planche de 4 images de la même mairie parisienne (petit Hôtel de Ville style Renaissance, toit en zinc, horloge sans chiffres),
dans le style défini, grille 2 × 2 régulière, fond blanc uni, vue isométrique identique, même taille et même angle :
1. de jour  2. de nuit, fenêtres éclairées  3. sous la neige  4. décorée pour une fête (drapeaux bleu-blanc-rouge, guirlandes).
```

**Planche Q2 · Parisiens**
```
Crée une planche de 16 petits personnages, dans le style défini, grille 4 × 4 régulière, fond blanc uni, vus en isométrique 3/4,
tous à la même échelle, de plain-pied, marchant vers la droite :
1. homme en costume  2. femme avec baguette  3. enfant avec ballon  4. personne âgée avec canne
5. cycliste  6. joggeuse  7. promeneur avec chien  8. touriste avec appareil photo
9. serveur de café avec plateau  10. agent de propreté avec balai  11. policier municipal  12. étudiante avec sac à dos
13. musicien avec accordéon  14. parent avec poussette  15. livreur à vélo  16. peintre avec chevalet.
```

**Planche Q3 · Véhicules**
```
Crée une planche de 9 véhicules, dans le style défini, grille 3 × 3 régulière, fond blanc uni, vue isométrique,
tous orientés dans la même direction (vers le bas à droite), à la même échelle :
1. petite voiture  2. taxi  3. bus vert  4. camionnette de livraison  5. camion-benne de propreté
6. ambulance  7. camion de pompiers  8. vélo en libre-service  9. trottinette.
```

**Planche Q4 · Rues**
```
Crée une planche de 9 tuiles de sol carrées vues en isométrique (losanges de même taille, qui s'emboîtent), dans le style défini,
grille 3 × 3 régulière, fond blanc uni :
1. rue droite  2. croisement  3. virage  4. place pavée  5. trottoir avec arbre
6. passage piéton  7. trottoir avec lampadaire  8. trottoir avec banc  9. pelouse avec fleurs.
```
