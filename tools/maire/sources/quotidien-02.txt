A) Ajouter une gamelle aux fontaines publiques :: Simple.
   bud-1 bon+1 | g+1 c+3 d+1 e+1
   > Les fontaines ont un petit bassin pour chiens.
B) Points d’eau dans les espaces canins :: Ciblé.
   bud-2 bon+1 | g0 c+2 d+2 e+1
   > Les enclos à chiens ont leur fontaine.
C) Rien :: Pas prioritaire.
   bon-1 | g0 c0 d+1 e0
   > Les chiens ont soif.

=== quo-064 | quotidien | Le froid dans les écoles en hiver
Des écoles mal chauffées obligent les enfants à garder leur manteau en classe.
A) Réparer les chaudières en urgence :: Chaleur.
   bud-10 services+2 bon+1 | g+2 c+2 d+1 e0
   > Les chaudières défectueuses sont remplacées.
B) Isoler les écoles :: Long terme.
   bud-25 services+1 ecologie+2 | g+1 c+2 d+1 e+3
   > Les écoles les plus froides sont isolées.
C) Distribuer des radiateurs d’appoint :: Rapide.
   bud-2 bon+1 ecologie-1 | g+1 c+2 d+1 e-1
   > Des radiateurs électriques sont livrés.

=== quo-065 | quotidien | Les ronds-points fleuris
Les habitants regrettent que les ronds-points et terre-pleins soient laissés en friche.
A) Fleurir tous les terre-pleins :: Embellir.
   bud-5 rec-0.1x60 bon+1 ecologie+1 | g+1 c+2 d+2 e+2
   > Les terre-pleins se couvrent de fleurs.
B) Les confier aux écoles et associations :: Participatif.
   bud-1 bon+1 ecologie+1 | g+2 c+2 d+1 e+2
   > Les élèves jardinent les terre-pleins.
C) Les laisser en friche :: Biodiversité.
   ecologie+1 bon-1 | g0 c0 d-1 e+2
   > Les herbes folles prospèrent.
